# Changelog

## 未リリース
- 統合版 (Bedrock Dedicated Server) に対応。
  - 新規作成ウィザードに「Java版 / 統合版」の選択を追加。統合版は遊び方プリセット・公式最新版 (正式版/プレビュー) の自動取得・手元 zip からの作成に対応。
  - 起動/停止、参加人数の表示、`server.properties` (統合版のキー) の編集、参加許可リスト (allowlist.json)、稼働中の OP 付与/解除。
  - 「バージョン」画面から BDS を更新（更新前にワールドを自動バックアップし、設定・ワールド・参加許可リストは保持）。
  - ワールド管理・バックアップが `worlds/` 配下に対応。配布ワールド (.mcworld) の取り込みに対応。
- ポート開放・Firewall を通信方式に合わせて設定するよう変更。
  - NetherNet (BDS 1.26.51 以降の既定): TCP の server-port（シグナリング）+ `server-udp-ports` の UDP 範囲を UPnP で開放。
  - RakNet: UDP の server-port を開放。
  - 統合版の Firewall は `bedrock_server.exe` のプログラム単位で TCP/UDP を許可。
  - `server-udp-ports` を「グローバル IP + 最大人数分の範囲」で自動入力する機能と、単一ポート・範囲不足などの警告を追加。
  - 接続画面に統合版の参加方法・必要なポート・シグナリングのサインイン状況・「つながらないとき」の切り分けを追加。
- UI: 新規作成ウィザードの入口をエディション選択カードに刷新、サーバー一覧・ヘッダーにエディションバッジを表示、詳細設定フォームの見出しを統一。
