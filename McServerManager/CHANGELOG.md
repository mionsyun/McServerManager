# Changelog

## 1.0.5
- 起動/停止/再起動ボタンの実行中テキストを動的変更（「起動中...」「停止中...」等）。
- 設定保存後に「✓ 設定を保存しました」の成功通知を3秒表示。
- バージョン一覧更新中のローディングインジケーター（プログレスバー・「取得中...」テキスト）を追加。
- OP/ホワイトリストの追加・削除後に操作結果メッセージを表示。
- コンソールタブのログビューアに横スクロールを追加。
- コンソールタブのボタン（📄📁⚠）にツールチップを追加。
- 起動安定化タブの Xms/Xmx 入力欄に有効範囲のヒントテキストを追加。
- 設定タブの「サーバー設定」DI 解決失敗バグを修正（ServerProvisioningService がインターフェース型を使用するよう修正）。
- マウスホイール処理での `Run` 要素に起因するクラッシュを修正。

## 1.0.2
- 設定タブで「設定を保存」ボタンを下部固定し、スクロールしなくても操作できるよう改善。

 - Addon/MOD の読み込みと互換性判定を改善し、誤検出や動作不良を修正しました。
 - コンソール／ログ表示における表示崩れやスクロール関連の不具合を修正しました。
 - ワールド選択・バックアップ周りの一部クラッシュとエラー処理を改善しました。
