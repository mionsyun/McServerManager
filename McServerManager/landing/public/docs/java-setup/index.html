🎮 なぜJavaが必要なの？

Minecraft Java Editionのサーバーは、Javaというプログラム上で動いています。サーバーを起動するにはまずJavaをPCにインストールする必要があります。

💡 ポイント: MaiPilotはJavaのパスを自動検出できるので、インストールさえ済めばあとはボタン一つでOKです。

📋 バージョン対応表

使いたいマイクラのバージョンに合ったJavaを選びましょう。

マイクラ バージョン必要な Javaおすすめ
1.7.10 ～ 1.16.5Java 8 以上Temurin 8 LTS
1.17 ～ 1.17.1Java 16 以上Temurin 17 LTS
1.18 ～ 1.20.4Java 17 以上Temurin 17 LTS
1.20.5 ～ 最新Java 21 以上Temurin 21 LTS ✅
迷ったら Java 21 (Temurin LTS) を入れればOK！ 最新バージョンに対応しており、古いバージョンのサーバーでも動作します。

🛠️ インストール手順（Windows）

1 ダウンロードページを開く

Adoptium 公式サイト にアクセスします。

  • Operating System: Windows
  • Architecture: x64
  • Package Type: JDK
  • Version: 21 (LTS) を選択
2 .msi インストーラーをダウンロード

「Latest - LTS」の行にある .msi リンクをクリックしてダウンロードします。

3 インストーラーを実行

ダウンロードしたファイルをダブルクリックして起動します。

⚠️ ここが重要！ 途中の「Custom Setup」画面で以下2つを必ず有効にしてください：
  • Add to PATH — ✅ 有効
  • Set JAVA_HOME — ✅ 有効
これにより、MaiPilot の自動検出やコマンドラインから java が使えるようになります。
4 インストール完了を確認

スタートメニューから「PowerShell」を開き、次のコマンドを入力します：

java -version

例: openjdk version "21.0.x" と表示されれば成功です。

5 MaiPilot で自動検出

MaiPilotを起動して、サーバーの設定タブにある 「自動検出」ボタン を押すだけ。
自動でJavaのパスが設定されます。

❓ よくある質問（FAQ）

Q. JDK と JRE、どちらを入れればいい？

A. JDK をおすすめします。JRE でもサーバーは動きますが、JDK のほうがトラブルシュート時に便利なツールが含まれています。

Q. Oracle JDK と Eclipse Temurin の違いは？

A. どちらも同じ OpenJDK ベースです。Temurin は完全無料で商用利用も可能。個人利用なら Oracle JDK でも問題ありませんが、ライセンスを気にしなくてよい Temurin がおすすめです。

Q. 「Java が見つかりません」エラーが出る

A. インストール時に「Add to PATH」を有効にしていない可能性があります。再インストールするか、手動でJavaのパスを設定してください。MaiPilotの「参照」ボタンから C:\Program Files\Eclipse Adoptium\jdk-21...\bin\java.exe を選択できます。

Q. 古いバージョン用に Java 8 も必要？

A. 1.16.5以下のサーバーでも Java 21 で動作するケースがほとんどです。まずは Java 21 で試し、問題があれば Java 8 を追加インストールしてください。

Q. 複数のJavaバージョンを共存できる？

A. はい。MaiPilotではサーバーごとに個別のJavaパスを指定できるので、バージョンごとに異なるJavaを使い分けられます。

❓ FAQ

Q. JDK vs JRE — which one?

A. JDK is recommended. It includes the runtime + useful tools for troubleshooting.

Q. Oracle JDK vs Eclipse Temurin?

A. Both are based on OpenJDK. Temurin is completely free for all uses. We recommend Temurin for simplicity.

Q. "Java not found" error?

A. Reinstall with "Add to PATH" enabled, or manually browse to java.exe using MaiPilot's Browse button.

Q. Can I install multiple Java versions?

A. Yes. MaiPilot lets you set a per-server Java path, so you can mix versions easily.
