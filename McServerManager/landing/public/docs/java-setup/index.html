🎮 なぜJavaが必要なの？

Minecraft Java EditionのサーバーにはJava実行環境が必要です。MaiPilotから自動セットアップするか、手動で導入できます。統合版（BDS）にはJavaは不要です。

💡 MaiPilotから導入: 対象サーバーの「サーバー設定」→「Java ランタイム」→「自動セットアップ」を選び、確認画面の内容を確認して進めます。対応するEclipse Temurin JREをAdoptium/GitHubから取得し、そのサーバーに設定します。インターネット接続が必要です。既存のJavaは「自動検出」や「参照」から指定できます。

🛠️ 手動インストール手順（Windows）

アプリの自動セットアップを使わず、自分でJavaを導入する場合の手順です。

1 ダウンロードページを開く

Adoptium 公式サイト にアクセスします。

  • Operating System: Windows
  • Architecture: x64
  • Package Type: JDK
  • Version: 対応表に合わせて選択（26.1以降は 25 (LTS)、1.20.5〜1.21.xは 21 (LTS)）
2 .msi インストーラーをダウンロード

選択したJavaバージョンの .msi インストーラーをダウンロードします。

3 インストーラーを実行

ダウンロードしたファイルをダブルクリックして起動します。

⚠️ ここが重要！ 途中の「Custom Setup」画面で以下2つを必ず有効にしてください：
  • Add to PATH — ✅ 有効
  • Set JAVA_HOME — ✅ 有効
これにより、MaiPilot の自動検出やコマンドラインから java が使えるようになります。
4 インストール完了を確認

スタートメニューから「PowerShell」を開き、次のコマンドを入力します：

java -version

選択したバージョンが表示されることを確認します。26.1用にJava 25を導入した場合の例: openjdk version "25.0.x"。

5 MaiPilot で自動検出

MaiPilotを起動して、サーバーの設定タブにある 「自動検出」ボタン を押すだけ。
自動でJavaのパスが設定されます。

❓ よくある質問（FAQ）

Q. JDK と JRE、どちらを入れればいい？

A. MaiPilotの自動セットアップはTemurin JREを導入します。手動で導入する場合は、実行環境に加えて調査用ツールを含むJDKも選べます。サーバー実装やMODの要件を確認してください。

Q. Oracle JDK と Eclipse Temurin の違いは？

A. どちらも同じ OpenJDK ベースです。Temurin は完全無料で商用利用も可能。個人利用なら Oracle JDK でも問題ありませんが、ライセンスを気にしなくてよい Temurin がおすすめです。

Q. 「Java が見つかりません」エラーが出る

A. 「サーバー設定」の「Java ランタイム」から「自動セットアップ」を使えます。既存のJavaを使う場合は「自動検出」を試すか、「参照」で対応バージョンの java.exe を選択してください。

Q. 古いバージョン用に Java 8 も必要？

A. 1.16.5以前の目安はJava 8です。古いサーバーやMODは新しいJavaで動かない場合があるため、対象バージョンの要件に合わせてください。MaiPilotではサーバーごとにJavaを指定できます。

Q. 複数のJavaバージョンを共存できる？

A. はい。MaiPilotではサーバーごとに個別のJavaパスを指定できるので、バージョンごとに異なるJavaを使い分けられます。

🎮 Why Do You Need Java?

Minecraft Java Edition servers need a Java runtime. MaiPilot can set it up for you, or you can install it manually. Bedrock Dedicated Server does not require Java.

💡 Set up Java in MaiPilot: Open the selected server's settings (サーバー設定), find Java Runtime (Java ランタイム), and choose Automatic Setup (自動セットアップ). Review the confirmation, then proceed to download a compatible Eclipse Temurin JRE from Adoptium/GitHub and set it for that server. Internet access is required. You can also use Auto Detect or Browse to select an existing Java installation.

🛠️ Manual Installation Steps (Windows)

Use these steps if you prefer to install Java yourself instead of using the app's automatic setup.

1 Open the Download Page

Go to Adoptium and select Windows, x64, JDK, and the version from the table: 25 (LTS) for 26.1 and later, or 21 (LTS) for 1.20.5–1.21.x.

2 Download the .msi Installer

Download the .msi installer for the Java version you selected.

3 Run the Installer

Double-click the downloaded file.

⚠️ Important! On the "Custom Setup" screen, make sure these are enabled:
  • Add to PATH — ✅ Enabled
  • Set JAVA_HOME — ✅ Enabled
4 Verify Installation

Open PowerShell and run: java -version

Check that the selected version is shown. For Java 25 installed for Minecraft 26.1, for example: openjdk version "25.0.x".

5 Auto-Detect in MaiPilot

Open MaiPilot, go to the Settings tab, and click "Auto Detect". Done!

❓ FAQ

Q. JDK vs JRE — which one?

A. MaiPilot's automatic setup installs a Temurin JRE. For a manual installation, you can also choose a JDK, which includes the runtime and troubleshooting tools. Check your server implementation and mod requirements.

Q. Oracle JDK vs Eclipse Temurin?

A. Both are based on OpenJDK. Temurin is completely free for all uses. We recommend Temurin for simplicity.

Q. "Java not found" error?

A. Use Automatic Setup under Java Runtime in the server settings. To use an existing installation, try Auto Detect or Browse to the java.exe for a compatible version.

Q. Can I install multiple Java versions?

A. Yes. MaiPilot lets you set a per-server Java path, so you can mix versions easily.
