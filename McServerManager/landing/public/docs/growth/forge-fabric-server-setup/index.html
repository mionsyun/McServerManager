Forge/Fabricサーバーの立て方（初心者向け）

MODサーバーは「ローダー・MOD・Java」の整合性が重要です。順番を守れば失敗を減らせます。

先に結論

  • 軽量・更新頻度重視なら Fabric。
  • 大型MODパック運用なら Forge。
  • 導入時は必ずローダー版とMOD版を揃える。

最短手順

  1. 使うMinecraftバージョンを先に固定。
  2. Forge または Fabric のサーバーセットアップを実行。
  3. `mods` フォルダへ対応MODを追加。
  4. 起動ログでローダー初期化とMOD読み込みを確認。
  5. エラーがあれば最後に入れたMODから戻す。

失敗しやすいポイント

  • クライアント専用MODをサーバーへ入れてしまう。
  • ローダーバージョンがMOD要求と不一致。
  • Java要件不足（特に新しめのバージョン）。

よくある質問

ForgeとFabricはどちらが軽いですか？
一般的にはFabricの方が軽量です。ただし入れるMOD次第で差は小さくなります。
Forge用MODをFabricで使えますか？
基本的に使えません。対応ローダーが一致したMODのみ使用してください。
起動しない時は何を先に見るべきですか？
ログ先頭のローダー初期化エラーと、最後に読み込んだMOD名を先に確認します。
