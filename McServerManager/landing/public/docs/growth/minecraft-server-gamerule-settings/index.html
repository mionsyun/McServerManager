マイクラサーバーのgamerule（ゲームルール）設定完全ガイド【2026年版】

対象: Java版 1.13以降 / OP権限（レベル2以上）が必要

gamerule ゲームルール サーバー設定 コマンド
設定を変更する前に必ずバックアップを取ってください。特にkeepInventoryなどはサーバーのプレイスタイルに大きく影響します。

gameruleとは？

gamerule（ゲームルール）はマイクラのゲームプレイに関する細かい挙動を制御するコマンドです。OPユーザーがゲーム内でコマンドを実行するだけで適用でき、サーバーを再起動する必要がありません。

/gamerule <ルール名> <値>

現在の設定値を確認するには値を省略します：

/gamerule keepInventory

よく使うgamerule一覧

gamerule名 デフォルト 説明
keepInventory false trueにすると死亡時にアイテムをドロップしない
mobGriefing true falseにするとCreeper爆発・Endermanのブロック持ち去りを防止
doDaylightCycle true falseにすると昼夜サイクルを停止（建築サーバー向け）
doWeatherCycle true falseにすると天気の変化を停止
doFireTick true falseにすると火の延焼を停止
pvp server.properties で設定 gameruleではなくserver.propertiesのpvp項目で制御
doMobSpawning true falseにするとMobの自然スポーンを停止
naturalRegeneration true falseにすると自然回復を停止（難易度UP）
announceAdvancements true falseにするとアドバンスメント達成のチャット通知を消す
randomTickSpeed 3 農作物の成長速度などに影響（大きくするほど高負荷）
maxEntityCramming 24 1ブロックに詰め込めるMob数の上限（サーバー負荷対策）
spawnRadius 10 スポーン地点からの最大半径（ブロック）

用途別おすすめ設定

友達サーバー（カジュアル）
/gamerule keepInventory true /gamerule mobGriefing false /gamerule announceAdvancements false
建築・クリエイティブ
/gamerule doDaylightCycle false /gamerule doWeatherCycle false /gamerule doFireTick false /gamerule doMobSpawning false
サーバー負荷軽減
/gamerule maxEntityCramming 16 /gamerule randomTickSpeed 3 /gamerule mobGriefing false

注意事項

  • randomTickSpeed を極端に大きくするとサーバーが高負荷になります。通常は 3〜10 の範囲で使用してください。
  • gameruleの設定はワールドデータに保存されるため、ワールドを削除するとリセットされます。
  • OP権限（レベル2以上）がないプレイヤーはgameruleコマンドを実行できません。
  • PvPの有効・無効は server.properties の pvp で設定します。

よくある質問

gameruleの設定はサーバー再起動後も保持されますか？
はい。/gamerule コマンドで設定した値はワールドデータに保存されるため、サーバーを再起動しても維持されます。
keepInventoryをtrueにするとどうなりますか？
プレイヤーが死亡してもアイテムをドロップせず、そのままインベントリを保持できます。友達同士のカジュアルサーバーに向いています。
gameruleはワールドごとに設定できますか？
Java版のgameruleはワールド（ディメンション）ごとではなく、サーバー全体に適用されます。ディメンション別に設定したい場合はデータパックを使う方法があります。
