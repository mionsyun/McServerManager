BAN の使い方

プレイヤーをBANする
/ban PlayerName 荒らし行為のため
BANすると次回ログイン時に「あなたはBANされています」と表示されます。理由を指定するとその理由も表示されます。
BANリストを確認する
/banlist players
/banlist ips
players でプレイヤー名BAN一覧、ips でIPBAN一覧が表示されます。
BANを解除する
/pardon PlayerName
BANを解除するとそのプレイヤーは再びサーバーに参加できるようになります。
BANデータは banned-players.json / banned-ips.json に保存されています。MaiPilotの「ワールド」→「フォルダを開く」から直接編集することも可能です。

OP権限の管理

OP権限を付与する
/op PlayerName
コンソールから実行するか、既にOP Lv4のプレイヤーが実行できます。
OP権限を剥奪する
/deop PlayerName

OPレベル（op-permission-level）の意味

レベルできること
1OP専用コマンドを使えるが、シングルプレイヤーのチート相当の制限あり
2gamerule・tp・time set などの管理コマンドが使える（デフォルト）
3ban・kick・whitelist などのプレイヤー管理コマンドが使える
4stop コマンドを含む全管理コマンドが使える（最高権限）
OPレベルのデフォルトは server.properties の op-permission-level で設定できます。

ホワイトリストの使い方

ホワイトリストを有効にすると、リストに登録されたプレイヤーのみサーバーに参加できます。友達だけのプライベートサーバーを作るときに便利です。

1. ホワイトリストを有効化する
/whitelist on
2. プレイヤーを追加する
/whitelist add PlayerName
3. 一覧を確認する
/whitelist list
whitelist.json を直接編集した後は /whitelist reload を実行して反映させてください。

ホワイトリストは ホワイトリスト・OP権限設定ガイド も参照してください。

よくある質問

マイクラサーバーでBANしたプレイヤーを解除するには？
コンソールまたはOP権限のあるプレイヤーが /pardon <プレイヤー名> を実行することでBANを解除できます。IPBANの場合は /pardon-ip <IPアドレス> を使います。
OPとホワイトリストの違いは何ですか？
OPはサーバー管理コマンドを実行できる権限です。ホワイトリストはサーバーに参加できるプレイヤーを制限する機能です。ホワイトリストを有効にすると、リストに載っていないプレイヤーは参加できなくなります。
OP権限のレベル（1〜4）の違いは何ですか？
レベル1は基本コマンドのみ。レベル2はgameruleやtpなどの管理コマンド。レベル3はban・kickなどのプレイヤー管理。レベル4はサーバーのstopも含む全権限です。
