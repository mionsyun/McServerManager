マイクラサーバーの必要スペック
メモリは何GB？ CPU・容量の確認手順

Windowsでサーバーを動かす前に、Minecraftの構成とPC全体の余裕を確認。人数だけの保証値ではなく、RAMの割り当て方と実際の負荷から判断します。

先に答え：人数だけで「必要RAM」は決まりません

  • Java版か統合版かと、サーバーのバージョン・MOD等の配布元要件を確認
  • PC全体のRAMとJavaのXmxは別。Windows、ゲーム本体、Javaのヒープ以外にも余裕を残す
  • 普段使うワールド・設定・参加条件で試し、CPU・RAM・ディスク・回線を切り分ける

MaiPilotはWindows 10/11用の管理アプリです。Java版のXms/Xmxを設定し、稼働中のCPU/RAMを確認できますが、性能不足を自動で解消したり、参加人数を保証したりするものではありません。

必要なメモリを決める3つの確認

  1. 構成を先に決めます。Java版／統合版、バージョン、MOD・プラグイン、ワールド、描画・シミュレーション距離などを整理。配布元に要件がある場合は優先します。
  2. WindowsのタスクマネージャーでPC全体を確認します。ゲーム本体や普段のアプリも使うなら、その状態でメモリの使用状況と空き容量を見ます。搭載RAMすべてをサーバーに割り当てないでください。
  3. 予定する使い方で試し、足りない部分を確認します。参加者、移動や新しい地形の生成、MODの処理が変わると負荷も変わります。アイドル時の値だけでは判断できません。
構成ごとに確認するポイント（人数・RAMの保証表ではありません）
使い方確認すること避けたい判断
同じPCでゲームも遊ぶWindows・クライアント・サーバーを合わせたメモリ使用量搭載RAM＝Xmxとして割り当てる
MOD・プラグインを追加する配布元の要件、実際の処理負荷、互換バージョン追加本数だけでRAMや人数を決める

Xms・Xmxと、PCの搭載RAMの違い

XmsはJavaヒープの初期サイズ、Xmxは最大サイズです。Javaプロセス全体が使うメモリの上限ではなく、Windowsや他のアプリに必要なRAMも含みません。統合版BDSにはJavaヒープ設定はありません。

Paper公式の起動例には-Xms4G -Xmx4Gという指定があります。これは設定方法の例であり、「4GBなら何人でも遊べる」「MaiPilotの必須スペック」という意味ではありません。

XmsとXmxを同じにするかは、サーバー実装・JVM・運用環境の方針に従います。一律に揃えることやRAMの増量だけで、すべてのラグが直るわけではありません。Paperの起動スクリプト案内は、現代のJVMでは追加フラグなしから試す方針も示しています。

詳しい設定項目はメモリ設定ガイド、Javaの準備はJavaセットアップガイドをご覧ください。サーバー実装・バージョンの公式要件を優先してください。

MaiPilotでメモリを設定し、稼働中の負荷を見る

  1. 対象のJavaサーバーを選び、現在の設定を控えます。ワールドのバックアップも残し、変更前後を比較できるようにします。
  2. 「サーバー設定」→「起動安定化・パフォーマンス」を開きます。Xms (MB)とXmx (MB)を確認・変更します。表示単位はMBです。
  3. 「設定を保存」を押し、サーバーを再起動します。起動中のJavaに新しいヒープ設定がその場で適用されるわけではありません。
  4. 「概要」でCPU・RAMを見て、コンソールのログと照らします。MaiPilotのRAM表示はサーバープロセスのワーキングセットを基にした値です。Javaヒープの使用量そのものや、PC全体の空きRAMとは区別してください。
  5. 同じ条件で再確認します。設定を一度にいくつも変えず、症状と使用状況を記録します。PC全体の状況はWindows側でも確認してください。
無料Windows版のダウンロード案内へスマホからPCへ引き継ぐ

個人・非商用利用は無料。Java版とBDSの管理に対応しますが、Xms/XmxはJava版向けの設定です。MaiPilot自体をLinuxのVPSへインストールする手順ではありません。

CPU・ストレージ・回線のどこが足りないかを分ける

メモリ

メモリ不足に関するエラーやプロセス終了があれば、Javaの割り当てとPC／ホスト側の上限を確認します。使用量の数字だけで原因を確定しません。

CPU・サーバー処理

負荷の高い処理や地形生成時の変化を確認。コア数やGHzの数字だけで性能・参加人数を保証できません。

ストレージ

ワールド・バックアップ用の空き容量と読み書きの負荷を確認。SSDも選択肢ですが、移動時の引っ掛かりだけでディスクが原因と断定しません。

ネットワーク

接続できない問題は、回線やルーター設定の確認も必要です。公開設定ガイドを参照し、RAM不足と混同しないでください。

Can't keep up!や一時停止は調査の手掛かりです。原因や改善を保証する表示ではありません。Paperでは公式トラブルシューティングも確認してください。

自宅PCかVPSかを選ぶとき

24時間PCを起動できない場合はホスティングも候補になります。CPU・メモリ制限・ストレージ・バックアップ・料金と、自分の構成での動作条件を比較してください。「人数に対してこのプランなら必ず足りる」とは断定できません。

よくある質問

マイクラサーバーのメモリは何GB必要ですか？
人数だけでは決まりません。エディション、バージョン、MOD等の配布元要件と実際の使い方を確認します。Java版のXmxだけでなく、Windows、ゲーム本体、ヒープ以外のメモリにも余裕を残し、同じ条件で試して判断してください。
XmsとXmxは同じ値にすべきですか？
サーバー実装やJVM、運用方針に従います。一律に同じ値にすることや、搭載RAMすべてを割り当てることは勧めません。XmxはJavaプロセス全体のメモリ上限ではなく、統合版BDSにはこの設定はありません。
MaiPilotのRAM表示はJavaヒープの使用量ですか？
稼働中のRAM表示はサーバープロセスのワーキングセットを基にしています。Javaヒープの使用量そのものや、Windows全体の空きメモリではありません。アプリの表示とWindows側の状況を分けて確認してください。
CPUコア数やGHzだけで必要スペックが分かりますか？
それだけでは決まりません。サーバーの構成と処理、ワールド、同時に動かすアプリ等の影響を受けます。予定する使い方で負荷とログを確認し、RAM・CPU・ディスク・回線を切り分けてください。
スマホからMaiPilotを使えますか？
MaiPilotを動かすにはWindows 10/11のPCが必要です。スマホで記事を読んでいる方は、公式ページのPC用リンクをコピー・共有して、Windows PCで続きを開いてください。
