Planet Minecraftの配布マップの入れ方
ダウンロードからサーバー導入まで

「保存したZIPをどこへ入れる？」「友達と遊べる？」を順に解決。まずワールド形式と対応エディションを確認し、元のワールドを残して導入します。

先に答え：Java版のワールドZIPを、停止中のサーバーへ取り込みます

  1. 配布ページでJava版・対応バージョン・追加要件を確認してワールドZIPを保存
  2. 対象サーバーを停止し、今のワールドをバックアップ
  3. MaiPilotの「ワールド」→「配布マップ導入 (.zip)」でZIPと導入先名を選択
  4. 取込後にサーバーを起動し、ゲームから接続して中身を確認

.schem / .schematicはワールドZIPとは別形式です。この取込手順は建築データの貼り付けやJava版・統合版間の変換には対応しません。

MaiPilotで取り込む手順へまずダウンロード方法を確認

MaiPilotはWindows 10/11用です。Windows PCでダウンロードしてください。

1. ダウンロード2. ZIPを取り込む3. 起動・確認手動で配置する場合表示されないとき

1. Planet Minecraftでワールドをダウンロードする

配布マップはプレイヤーが公開したワールドデータです。Planet MinecraftのMaps一覧にはワールドのほか、Schematic、動画、シードの投稿もあります。投稿名だけで判断せず、作者の説明とファイル形式を確認してください。

  1. 1作品の配布ページを開きます。Java版か統合版か、対応するMinecraftバージョン、マルチプレイ対応、必要なMOD・リソースパック・設定を確認します。
  2. 2作者が案内しているワールドのダウンロード先を選びます。Java版ではワールドデータ入りのZIPを選びます。広告のダウンロードボタンや無関係な実行ファイルと取り違えないでください。
  3. 3ZIPを保存します。MaiPilotで取り込む場合は事前の解凍は不要です。候補の目印はlevel.dat、またはregionを含むワールドフォルダーです。ZIPが入れ子なら、内側のワールドZIPを取り出して選びます。
作者の利用条件と指定バージョンを優先してください。新しいバージョンで保存したワールドを古いサーバーへ戻せるとは限りません。ダウンロードした原本も残しておきます。

ワールドZIP

Java版の配布ワールドなら、このページの取込手順へ。複数候補が見つかったら、説明に沿ったワールドフォルダーを選びます。

Schematic・シード・動画

ワールドの取込用ZIPとは異なります。ファイル名を.zipに変えてもワールドにはなりません。投稿者が案内する別の導入方法を確認します。

統合版の配布ワールド

MaiPilotのBDS用画面では.mcworld / .zipを選べます。統合版用のワールドが必要で、Java版ワールドを自動変換する機能ではありません。

2. MaiPilotの「ワールド」からZIPを取り込む

MaiPilot 2.2.0の実装・画面名に合わせたJava版の手順です。対象のJavaサーバーを用意してから進めます。

  1. 1対象サーバーを停止します。配布マップの導入とワールドの切り替えは停止中に行います。既存ワールドはバックアップを作成しておきます。
  2. 2左の「ワールド」を開きます。「配布マップ導入 (.zip)」の「ファイル」横にある「選択」から、保存したZIPを指定します。
  3. 3「導入元フォルダ」を確認します。候補が1つなら自動選択、複数なら使うワールドを選びます。「導入先ワールド名」には、既存と重ならない名前を付けます。
  4. 4「配布マップを導入」を押します。Java版でコマンドブロックが無効なときは、有効化の確認が出ます。作者の要件を読んで判断してください。
  5. 5導入完了と「使用中」のワールド名を確認します。取込後は導入先ワールドへ設定が切り替わり、次回起動時に適用されます。
「同名ワールドは上書きして導入」は既存データを置き換えます。まず別名で取り込み、原本とバックアップを残してください。この導入操作が上書き前に自動バックアップするとは限りません。
無料Windows版のダウンロード案内へ

Windows 10/11用。個人・非商用利用は無料です。Minecraft本体や配布マップの利用条件は別途ご確認ください。

3. サーバーを起動して、ゲーム内で確認する

  1. マップが指定するバージョン・MOD・ゲームモードを確認して起動します。
  2. コンソールで起動完了を確認します。起動ログだけでは、正しいマップや仕掛けの動作までは確認できません。
  3. ゲームから接続し、想定した建物・地形・開始地点かを確認します。既存のプレイヤーデータ等によって開始位置が異なる場合もあります。
  4. 友達を招く前に、作者が指定する追加ファイルとマルチプレイ条件を全員で揃えます。外部接続は公開・ポート設定も別途確認します。

コマンドブロック、gamemode、必要なMODやリソースパックの条件は作品によって違います。「接続するだけで必ず遊べる」とは限りません。

手動で配置する場合：コピー先と切り替え方

ZIPを自分で展開する場合も、サーバーの停止とバックアップを先に行います。Java版では、level.datまたはregionを含むワールドフォルダーをサーバー直下へ、既存と異なる名前で配置します。

例：server/adventure-map/level.dat。二重フォルダーの外側ではなく、ワールドデータが入っている階層を選びます。MaiPilotの「ワールド」の「フォルダを開く」は、選択中のワールドを開くボタンです。サーバー直下と取り違えないでください。

配置後は「一覧更新」→追加したワールドを選択→「このワールドに切り替え」。起動前に「使用中」の名前を確認します。統合版はサーバー直下のworlds配下に保存され、Java版とは配置が異なります。

配布マップが表示されない・遊べないとき

Planet Minecraftのマップはどこからダウンロードしますか？
作品の配布ページで、作者が指定するワールドのダウンロード先を選びます。Java版・統合版、対応バージョン、必要なMOD等を確認してください。Schematicやシードだけの投稿は、ワールドZIPの取込手順とは別です。
ZIP内にワールドが見つからないと表示されます
ワールドデータ入りのZIPか確認してください。MaiPilotはlevel.datまたはregionを含むフォルダーを候補にします。内側に別のZIPがある場合は取り出し、複数候補なら正しい導入元フォルダーを選びます。.schemや.schematicはこの取込の対象ではありません。
元のワールドに戻せますか？
別名で取り込み、元のフォルダーを残した場合は、サーバーを停止して「ワールド」の一覧から元を選び「このワールドに切り替え」を押します。同名で上書きした場合は、残しておいたバックアップからの復元が必要です。
友達に追加のMODは必要ですか？
作品によります。マップ作者が指定するMOD、リソースパック、バージョン、マルチプレイ対応条件を確認してください。Java版と統合版の違い、家庭用ゲーム機の接続制限、回線の公開条件も別途確認が必要です。
スマホだけでMaiPilotを使えますか？
MaiPilotはWindows 10/11用です。Windows PCでダウンロードしてください。
