server.propertiesおすすめ設定（公開向け）

公開サーバーで迷いやすい設定を、まず触る項目だけに絞って解説します。

まず設定する項目

項目推奨理由
online-modetrueなりすまし防止
difficultynormal運用バランスが良い
view-distance8〜10負荷と快適性のバランス
max-players実人数+2過負荷を避ける
motd短く明確に参加者向け案内

変更手順

  1. サーバー停止中に `server.properties` を編集。
  2. 文字コードはUTF-8で保存（BOMなし推奨）。
  3. 再起動してログに設定反映を確認。

よくある質問

view-distanceを上げると何が起きますか？
描画範囲が広がる分CPU・メモリ負荷が増えます。人数が多いサーバーでは低めが安定します。
online-modeをfalseにしても大丈夫ですか？
公開サーバーでは非推奨です。認証が無効になり、なりすましリスクが増えます。
max-playersは大きめにしても問題ないですか？
実際の運用人数より少し多い程度が安全です。過大設定はラグやクラッシュの原因になります。
