詰まりポイント早見表

LANのみOK

外部のみNG

CGNAT/共有回線の制約を疑う。

先に結論

  • まずローカル接続できるかを確認する。
  • 次にLAN接続、最後に外部接続の順で確認する。
  • 外部だけ失敗する場合は回線仕様（CGNAT/共有回線）を疑う。

チェック手順

  1. サーバープロセスがポートをListenしているか確認。
  2. Windows Firewallの受信ルールを確認。
  3. ルーターの転送先IPが現在のPCと一致しているか確認。
  4. 二重ルーター構成かどうか確認。
  5. CGNAT/共有回線で外部開放不可ではないか確認。

詰まりやすい原因トップ3

  • PC再起動でLAN IPが変わり、転送先がズレる。
  • セキュリティソフト側で追加ブロックされる。
  • ISP仕様で外部からの着信がそもそも不可。
