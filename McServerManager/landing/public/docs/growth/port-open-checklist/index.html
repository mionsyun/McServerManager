先に結論

  • まずローカル接続できるかを確認する。
  • 次にLAN接続、最後に外部接続の順で確認する。
  • 外部だけ失敗する場合は回線仕様（CGNAT/共有回線）を疑う。

チェック手順

  1. サーバープロセスが25565ポートをListenしているか確認。
  2. Windows Firewallの受信ルールを確認。
  3. ルーターの転送先IPが現在のPCと一致しているか確認。
  4. 二重ルーター構成かどうか確認。
  5. CGNAT/共有回線で外部開放不可ではないか確認。

よくある質問

LANでは入れるのに外部から入れないのはなぜですか？
ルーター転送先IPのずれ、CGNAT、共有回線制限のいずれかが原因です。ローカル成功後は外部経路だけを重点確認してください。
UPnPが失敗したらどうすればいいですか？
手動ポート転送へ切り替え、Firewall受信ルールとLAN IP固定化まで行うと再発を抑えられます。
ポート25565以外を使っても問題ありませんか？
問題ありません。サーバー設定とルーター設定、接続側入力のポート番号を同じに揃える必要があります。
