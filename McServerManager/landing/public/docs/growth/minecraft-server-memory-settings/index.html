マイクラサーバーのメモリ設定（Xms/Xmx目安）

メモリは多ければ良いわけではありません。用途別の目安で決めるのが最短です。

先に結論

  • 少人数・バニラ: `Xmx 2G` から開始。
  • 中規模・軽量プラグイン: `Xmx 4G` 目安。
  • MOD多め・人数多め: `Xmx 6G〜8G` を段階調整。
  • `Xms` は `Xmx` の 50〜75% で十分。

用途別の目安

用途推奨Xms推奨Xmx
バニラ 1〜5人1G2G
Paper 5〜15人2G4G
MOD 10人前後3G6G
MOD重め 15人以上4G8G

設定のコツ

  1. まず `Xmx` を決めてから `Xms` を設定する。
  2. TPS低下やGC停止が出るなら `Xmx` を1Gずつ増やす。
  3. OS側の空きメモリを最低2GB以上残す。

よくある質問

Xmxを大きくすると必ず速くなりますか？
必ずしも速くなりません。割り当て過多はGC停止を長くし、逆にカクつく場合があります。
XmsはXmxと同じ値にすべきですか？
固定運用でなければ同値にしなくて問題ありません。Xmxの50〜75%から始めるのが扱いやすいです。
どれくらいの頻度で見直すべきですか？
プレイヤー数やMOD/プラグインを増やしたタイミングで見直すのが効果的です。
