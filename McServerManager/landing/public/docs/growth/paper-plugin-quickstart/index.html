Paperサーバーにプラグインを入れる最短手順

「入れたら落ちた」を防ぐための、短い手順ガイドです。

想定読了: 5分 対象: Paper運用者 目的: 安全導入
※この記事には広告・PRリンクを含みます。

導入前チェック

停止状態にする

ファイル破損と競合を防ぐ。

互換性確認

MC/Paper/Javaの3点一致を確認。

バックアップ

導入前の退避で即ロールバック可能に。

先に結論

  • 導入前にサーバー停止とバックアップを必ず行う。
  • プラグインは1つずつ追加して起動確認する。
  • 対応Minecraft/Paperバージョンを事前確認する。

最短手順

  1. サーバー停止。
  2. `plugins` フォルダへ対象JARを配置。
  3. サーバー起動し、`plugins` コマンドやログでロード確認。
  4. 設定ファイルが生成されたら必要箇所のみ編集。
  5. 問題なければ次のプラグインを追加。

うまくいかない時

  • `UnsupportedClassVersionError` はJava不一致の可能性。
  • `NoSuchMethodError` はAPI/バージョン不一致の可能性。
  • 起動不能時は新規追加したJARを一旦外して再起動。

よくある質問

プラグインは何個まで入れて大丈夫ですか？
上限はありませんが、負荷と競合が増えるため少数から段階的に追加する運用が安全です。
入れた後にサーバーが落ちたらどうすればいいですか？
直前に追加したJARを外して再起動し、ログのエラー行から依存不足やバージョン不一致を確認します。
Paper本体更新とプラグイン更新は同時にしてもいいですか？
同時更新は原因切り分けが難しくなります。1つずつ更新して起動確認するのがおすすめです。
