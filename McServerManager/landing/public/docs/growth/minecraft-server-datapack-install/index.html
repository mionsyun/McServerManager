マイクラサーバーにデータパックを入れる方法【2026年版】

対象: Java版 1.13以降 / Vanilla・Paper・Purpurサーバー

データパック Java版 サーバー管理 MaiPilot
サーバーを止めてからファイルを配置し、起動後に /reload するのが基本の手順です。

データパックとは？

データパックはJava版マイクラに標準搭載されているカスタマイズ機能です。
レシピ変更・カスタムアドバンスメント・カスタムディメンション追加など、Modなしでゲームを拡張できます。

クライアント不要
プレイヤー側の操作なしでサーバーに導入できます。
バニラ互換
Vanilla / Paper / Purpur どのサーバーにも対応します。
zip形式で配布
PlanetMinecraftやMCDFなど各サイトから入手できます。

導入手順（4ステップ）

1
データパックを入手する

信頼できるサイト（PlanetMinecraft・Modrinth・MCDF等）からダウンロードします。拡張子が .zip のままでOKです。

2
サーバーを停止する

MaiPilotの「停止」ボタン、またはコンソールで stop コマンドを実行します。ファイルを書き込むまえにサーバーを止めることで破損を防ぎます。

3
datapacks フォルダに配置する

サーバーのワールドフォルダ内の datapacks フォルダに zip ファイルをそのままコピーします。

（サーバーフォルダ）/world/datapacks/my-datapack.zip
MaiPilotの「ワールド」タブ → 「フォルダを開く」でエクスプローラーから直接配置できます。
4
サーバーを起動して /reload する

サーバーを起動後、コンソールまたはゲーム内チャットで以下を実行します。

/reload

反映を確認するには /datapack list を実行してください。有効なパック名が緑色で表示されます。

配布ワールドに付属している場合

配布ワールドをダウンロードすると、解凍したフォルダ内に datapacks/ フォルダが含まれていることがあります。

  1. 配布ワールドのフォルダをサーバーのワールドフォルダ（world/）として配置する
  2. datapacks フォルダもワールドフォルダの直下に含まれているか確認する
  3. サーバーを起動すると自動的に読み込まれます
ワールドフォルダ名をサーバーの level-name 設定と一致させることを忘れずに。

よくあるトラブルと解決策

/datapack list に表示されない
datapacks フォルダの場所が間違っている可能性があります。world/ の直下に配置されているか確認してください。
エラーメッセージが出る
データパックがサーバーのバージョンに対応していない可能性があります。配布ページで動作バージョンを確認してください。
複数パックが競合する
/datapack disable <名前> で不要なパックを無効化してください。優先度は /datapack enable <名前> first/last で調整できます。

よくある質問

データパックはModと何が違いますか？
データパックはゲーム本体の機能を拡張するバニラ互換の仕組みで、クライアント側の変更が不要です。Modはゲームバイナリを改変するためサーバー・クライアント両方への導入が必要です。
配布ワールドのdatapacksフォルダはどこに置きますか？
サーバーのワールドフォルダ（例: world/）直下にある datapacks フォルダに配置します。配布ワールドに付属している場合はそのまま同じ構造でコピーしてください。
複数のデータパックを同時に使えますか？
可能です。ただし同じアドバンスメントやレシピを上書きするパック同士は競合します。/datapack list で有効なパックを確認し、優先度を調整してください。
