自宅PCで立てる場合の3つの課題

① ポート開放がわからない

ルーターの設定はメーカーごとに画面が違い、慣れていないと30〜60分かかることも。

② コマンド操作が必要

start.batの作成・JVM引数設定・ポート番号の書き換えなど、黒い画面との格闘が続く。

③ バックアップが面倒

手動フォルダコピーは忘れがち。クラッシュでワールドデータが消えた経験をした人も多い。

MaiPilotで管理操作をまとめる

MaiPilotはWindows向けのマイクラサーバー管理ツールです。サーバーの作成・起動停止や対応する設定を日本語GUIで操作できます。回線やルーター、MODごとの設定は別途必要になる場合があります。

  • 日本語GUIでボタンひとつ操作
  • 対応ルーター向けのUPnP設定補助と接続確認機能を内蔵
  • スケジュール自動バックアップ
  • Java版のVanilla / Paper / Forge / Fabric / Spigot / Purpurと、統合版BDSに対応

MaiPilotでのサーバー構築手順（3ステップ）

1

MaiPilotをダウンロード・インストール

公式サイト（maipilot.jp）からインストーラーをダウンロード。Windows PCでインストーラーを実行し、表示される内容を確認しながら進めてください。個人・非商用利用は無料です。

2

新規サーバーを作成

新規サーバー作成画面でJava版または統合版を選び、種類・バージョンなどを設定します。Java版は対応するJavaが必要で、MaiPilotの自動セットアップも利用できます。

3

ネットワーク設定と接続を確認する

「ネットワーク」で接続診断やUPnP・ファイアウォール設定を確認します。UPnPは対応ルーターで利用でき、回線によってはポート開放できない場合もあります。診断結果だけで全プレイヤーの接続を保証することはできないため、外部回線から実際に接続を試してください。

よくある質問

Javaは別途インストールが必要ですか？
Java版ではサーバーバージョンに合うJavaが必要です。MaiPilotからEclipse Temurinを自動セットアップするか、手動で導入できます。統合版BDSにはJavaは不要です。
友達がサーバーに繋がらない場合はどうすれば？
「ネットワーク」で診断結果を確認し、ファイアウォール・ルーター・回線条件を順に切り分けてください。診断は補助で、接続できることを保証するものではありません。
レンタルサーバーとどちらがおすすめですか？
自宅PCなら既存の機材を使えますが、電気代や回線費、稼働中のPC管理も考慮してください。24時間稼働の必要性、予算、各サービスの条件を比較して選びます。
バックアップは自動でできますか？
定期自動バックアップに対応しています。「バックアップ」で自動バックアップの間隔や保持世代数を確認・設定してください。
