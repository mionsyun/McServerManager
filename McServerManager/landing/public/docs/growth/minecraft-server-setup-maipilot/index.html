自宅PCで立てる場合の3つの課題

① ポート開放がわからない

ルーターの設定はメーカーごとに画面が違い、慣れていないと30〜60分かかることも。

② コマンド操作が必要

start.batの作成・JVM引数設定・ポート番号の書き換えなど、黒い画面との格闘が続く。

③ バックアップが面倒

手動フォルダコピーは忘れがち。クラッシュでワールドデータが消えた経験をした人も多い。

MaiPilotを使えばこれらが全部解決する

MaiPilotは、これらの課題をまとめて解決するために開発されたWindows向けマイクラサーバー管理ツールです。日本語対応のGUIで、コマンド操作なしにサーバー管理が完結します。

  • 日本語GUIでボタンひとつ操作
  • ポート開放（UPnP自動設定）＋接続確認チェッカー内蔵
  • スケジュール自動バックアップ
  • Vanilla / Paper / Forge / Fabric / Spigot / Purpur の6種対応

MaiPilotでのサーバー構築手順（3ステップ）

1

MaiPilotをダウンロード・インストール

公式サイト（maipilot.jp）からインストーラーをダウンロード。ウィザード形式で「次へ」をクリックするだけで完了します。

2

新規サーバーを作成

「新しいサーバーを作成」をクリックして、サーバーの種類・Minecraftバージョン・メモリをGUIで選択。コマンドの入力は一切不要です。

3

ポート開放を完了させる

「ネットワーク」タブからUPnP自動設定・ファイアウォール設定・接続確認テストをGUI上で実行。「ポート開放チェック」ボタンを押すだけで友達が繋がれる状態か確認できます。

よくある質問

Javaは別途インストールが必要ですか？
MaiPilotがJavaのインストールをガイドします。手順に従って進めるだけで環境を整えられます。
友達がサーバーに繋がらない場合はどうすれば？
MaiPilotの「ネットワーク」タブにトラブルシューティングガイドが内蔵されています。ポート開放チェック・ファイアウォール設定・接続確認をまとめて確認できます。
レンタルサーバーとどちらがおすすめですか？
友達と気軽に遊ぶ用途で自宅PCがある場合はMaiPilot+自宅PCがコスト面で有利です。24時間稼働が必要な場合はレンタルサーバーをおすすめします。
バックアップは自動でできますか？
はい。定期自動バックアップの設定が可能です。「バックアップ」タブから間隔と保存先を指定するだけです。
