マイクラサーバー立て方ガイド（セットアップノート） Setup Notes

※本ページにはプロモーション（PR）を含む場合があります
This page may include promotional links (PR).
Language

セットアップ手順

  1. インストーラーを実行してインストールします。
  2. アプリを起動し、Java版または統合版BDSを選びます。Java版ではサーバー種別も選択します。
  3. Java版では対応するJavaを自動セットアップするか、Javaパスを指定します。メモリやポートなど、選んだ版で使える項目を設定します。
  4. 起動ボタンでサーバーを開始します。

※ 起動前に Java バージョンを自動チェックします。MOD/プラグインは Modrinth 連携で検索・導入できます。

Quick Setup

  1. Run the installer and finish setup.
  2. Open the app and choose Java Edition or Bedrock Dedicated Server. For Java, also select a server type.
  3. For Java Edition, use automatic Java setup or select a compatible java.exe. Configure memory, ports and other options supported by the selected edition.
  4. Press Start to launch the server.

Java version compatibility is checked before start. MODs/plugins can be searched and installed via Modrinth integration.

動作環境

  • Windows 10/11
  • Java版は対応するJavaが必要（自動セットアップ可）。統合版BDSには不要
  • ネット接続 (バージョン取得/公開IP確認)

Requirements

  • Windows 10/11
  • A compatible Java runtime for Java Edition (automatic setup available); not needed for BDS
  • Network connection (version info / public IP checks)

注意点

  • 設定の一部は保存できますが、反映は再起動後です。
  • UPnP/Firewall は環境により失敗する場合があります。
  • 共有回線（寮・学校・マンション一括回線など）では、上位ネットワーク制限でポート開放に失敗することがあります。
  • クラッシュ時はログフォルダや crash-reports を確認してください。

Notes

  • Some settings require a server restart to take effect.
  • UPnP/Firewall actions may fail depending on the environment.
  • On shared networks (dorm/school/apartment internet), upstream restrictions can block port forwarding.
  • If a crash happens, check logs and crash-reports.

まず詰まりやすい点

Java が古いと起動しません。起動前の警告を確認してください。
友だちが入れない場合は「ネットワーク」タブで公開チェックを実行。
エラー時は「ログフォルダ」「クラッシュレポート」を開くと原因が分かります。

Quick fixes

If Java is too old, the server will not start. Check the warning before launch.
If friends cannot join, run the public check in the Network tab.
For errors, open the Logs or Crash Reports folder.

セキュリティ/プライバシー

  • ワールド・設定・バックアップは端末内に保存し、自動アップロードしません。任意のJava版リソースパック配布を開始した場合は、選んだZIPをCloudflare経由で公開できます。
  • 解析/テレメトリは行いません。ログの自動送信なし。
  • Firewallルールの変更時は理由を表示して管理者権限を要求します。UPnPは対応ルーターの設定・許可に依存します。
  • 保存先/ログ/クラッシュレポートはワンクリックで開けます。
  • インストーラーのSHA256は更新マニフェストで確認できます。

Security & Privacy

  • Worlds, settings and backups are stored locally and are not automatically uploaded. Optional Java resource-pack distribution can publish the selected ZIP through Cloudflare.
  • No telemetry. Logs are not sent automatically.
  • Firewall-rule changes request administrator elevation with an explanation. UPnP depends on router support and permission.
  • Data, logs, and crash reports are one click away.
  • The installer SHA256 is available in the update manifest.

通信先の例

  • launchermeta.mojang.com: Minecraft バージョン一覧
  • api.papermc.io: Paper バージョン/ダウンロード
  • api.purpurmc.org: Purpur バージョン/ダウンロード
  • meta.fabricmc.net: Fabric Loader/Installer
  • maven.minecraftforge.net: Forge メタデータ/インストーラ
  • hub.spigotmc.org: Spigot BuildTools.jar の取得
  • api.ipify.org: 公開 IP の取得

※ BuildTools は追加で Git/SpigotMC などへアクセスする場合があります。

これは代表例です。利用する機能に応じて、Javaの配布元、統合版BDSやMaiPilot更新の配布先、任意のリソースパック配布用Cloudflareなどにも通信します。

Example Network Endpoints

  • launchermeta.mojang.com: Minecraft version manifest
  • api.papermc.io: Paper versions/downloads
  • api.purpurmc.org: Purpur versions/downloads
  • meta.fabricmc.net: Fabric Loader/Installer
  • maven.minecraftforge.net: Forge metadata/installer
  • hub.spigotmc.org: Spigot BuildTools.jar
  • api.ipify.org: Public IP lookup

BuildTools may access Git/SpigotMC sources for builds.

These are examples. Depending on the features used, the app also contacts Java distributors, BDS and MaiPilot update download services, and Cloudflare for optional resource-pack distribution.
