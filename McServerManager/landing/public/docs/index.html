マイクラサーバー立て方ガイド（セットアップノート） Setup Notes

※本ページにはプロモーション（PR）を含む場合があります
This page may include promotional links (PR).
Language

セットアップ手順

  1. インストーラーを実行してインストールします。
  2. アプリを起動し、サーバー種別（Vanilla / Paper / Spigot / Forge / Fabric / Purpur）を選びます。
  3. Java パスを指定し、メモリやポートを設定します。
  4. 起動ボタンでサーバーを開始します。

※ 起動前に Java バージョンを自動チェックします。MOD/プラグインは Modrinth 連携で検索・導入できます。

Quick Setup

  1. Run the installer and finish setup.
  2. Open the app and choose a server type (Vanilla / Paper / Spigot / Forge / Fabric / Purpur).
  3. Select your java.exe, set memory and port.
  4. Press Start to launch the server.

Java version compatibility is checked before start. MODs/plugins can be searched and installed via Modrinth integration.

動作環境

  • Windows 10/11
  • Java (server.jar 実行用)
  • ネット接続 (バージョン取得/公開IP確認)

Requirements

  • Windows 10/11
  • Java (for server.jar)
  • Network connection (version info / public IP checks)

注意点

  • 設定の一部は保存できますが、反映は再起動後です。
  • UPnP/Firewall は環境により失敗する場合があります。
  • 共有回線（寮・学校・マンション一括回線など）では、上位ネットワーク制限でポート開放に失敗することがあります。
  • クラッシュ時はログフォルダや crash-reports を確認してください。

Notes

  • Some settings require a server restart to take effect.
  • UPnP/Firewall actions may fail depending on the environment.
  • On shared networks (dorm/school/apartment internet), upstream restrictions can block port forwarding.
  • If a crash happens, check logs and crash-reports.

まず詰まりやすい点

Java が古いと起動しません。起動前の警告を確認してください。
友だちが入れない場合は「ネットワーク」タブで公開チェックを実行。
エラー時は「ログフォルダ」「クラッシュレポート」を開くと原因が分かります。

Quick fixes

If Java is too old, the server will not start. Check the warning before launch.
If friends cannot join, run the public check in the Network tab.
For errors, open the Logs or Crash Reports folder.

セキュリティ/プライバシー

  • データは端末内のみ保存。クラウド送信なし。
  • 解析/テレメトリは行いません。ログの自動送信なし。
  • 管理者権限は Firewall/UPnP 操作時のみ。理由を表示します。
  • 保存先/ログ/クラッシュレポートはワンクリックで開けます。
  • インストーラーの SHA256 を配布ページに掲載し、改ざん検知が可能です。

Security & Privacy

  • Data stays on your PC. No cloud storage.
  • No telemetry. Logs are not sent automatically.
  • Admin rights are requested only for Firewall/UPnP actions with reasons shown.
  • Data, logs, and crash reports are one click away.
  • SHA256 hashes are posted on the download page for integrity checks.
