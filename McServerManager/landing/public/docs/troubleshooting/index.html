トラブルシュート Troubleshooting

Language

まず見る場所

  • コンソールタブのログ（リアルタイムでエラーを確認）
  • ログフォルダ（logs）— “ログフォルダを開く” ボタンで直接アクセス
  • クラッシュレポート（crash-reports）— 同じくワンクリックで開けます

Where to look first

  • Console tab logs (check errors in real time)
  • Logs folder (logs) — open directly from the "Open logs folder" button
  • Crash reports (crash-reports) — also one-click accessible

よくある原因

  • Java バージョン不足 — 起動前に自動チェックされますが、警告を無視すると起動失敗します。
  • ポート競合 — 25565 が別プロセスで使用中の場合、バインドに失敗します。
  • MOD/プラグインの相性 — バージョン不一致や相互競合でクラッシュすることがあります。
  • メモリ不足 — MOD 大量導入時は割り当てメモリを増やしてください。
  • ワールド破損 — 強制終了後などに発生。バックアップから復元できます。

Common causes

  • Java version mismatch — Auto-checked before start, but ignoring the warning causes startup failure.
  • Port conflicts — Another process using 25565 will block binding.
  • Mod/plugin compatibility — Version mismatches or conflicts can cause crashes.
  • Not enough memory — Increase allocated memory when running many mods.
  • World corruption — May happen after a forced shutdown. Restore from a backup.

復旧の流れ

  1. 最新ログを確認— コンソールタブまたは logs フォルダでエラー行を探す。
  2. Java/ポート設定を見直す。
  3. MOD/プラグインが原因なら、直近追加したものを外して再起動。
  4. 必要ならバックアップから復元（バックアップタブからワンクリック）。

自動再起動 / クラッシュ復旧

  • MaiPilot はクラッシュを検知すると自動でサーバーを再起動します。
  • 繰り返しクラッシュする場合は自動再起動を停止し、ログで根本原因を確認してください。
  • リアルタイムモニタリング（CPU・TPS・プレイヤー数）でパフォーマンス低下を事前に察知できます。

MOD/プラグインのトラブル

  • UnsupportedClassVersionError → Java バージョンが低すぎます。
  • NoSuchMethodError → MOD/プラグインの対応バージョンを確認。
  • 起動不能 → 新規追加した JAR を外して再起動。
  • 不安定な MOD は Modrinth 検索でアップデート版を探してみてください。

Recovery flow

  1. Check the latest logs — look for error lines in the Console tab or logs folder.
  2. Review Java and port settings.
  3. If a mod/plugin is the cause, remove the most recently added JAR and restart.
  4. Restore from backup if needed (one click from the Backups tab).

Auto-restart / crash recovery

  • MaiPilot automatically restarts the server when a crash is detected.
  • If crashes repeat, disable auto-restart and check logs for the root cause.
  • Real-time monitoring (CPU, TPS, players) helps detect performance issues early.

MOD/plugin troubleshooting

  • UnsupportedClassVersionError → Java version too low.
  • NoSuchMethodError → Check the mod/plugin's supported version.
  • Cannot start → Remove the newly added JAR and restart.
  • For unstable mods, try searching for an updated version via Modrinth integration.
