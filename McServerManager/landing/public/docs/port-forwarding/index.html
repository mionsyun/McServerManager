マイクラポート開放チェックリスト Port Forwarding Checklist

Language

マイクラサーバーのポート開放でまず確認すること

  • サーバーは起動中か
  • ポート番号（通常25565）は正しいか
  • 同一ポートを他のアプリが使用していないか

First checks

  • Is the server running?
  • Is the port number correct?
  • Is another app using the same port?

UPnPが失敗する場合

  • ルーター側でUPnPが無効
  • 二重ルーターでUPnPが届かない
  • IPv6/CGNAT環境で外部公開できない
  • 共有回線（寮・学校・マンション一括回線など）で、上位側にポート開放権限がない

If UPnP fails

  • UPnP is disabled on the router
  • Double router setup blocks UPnP
  • IPv6/CGNAT prevents inbound access
  • Shared networks (dorm/school/apartment internet) do not allow port forwarding at the upstream gateway

ルーター設定のチェック

  1. ポート開放先が正しいPCのIPか確認。
  2. TCP/UDP両方が必要な場合は両方開放。
  3. LAN IPが変わらないように固定化。

よく検索されるトラブル例

  • マイクラポート開放 できない
  • 25565 ポート開放 確認方法
  • マイクラ サーバー ポート開放 友達が入れない

Router checklist

  1. Port forwarding points to the correct PC IP.
  2. Open TCP/UDP as needed.
  3. Use a fixed LAN IP if possible.

Firewallの確認

  • アプリのFirewallルールが作成されているか
  • セキュリティソフトが通信を遮断していないか

Firewall checks

  • Firewall rules are created
  • Security software is not blocking the port
