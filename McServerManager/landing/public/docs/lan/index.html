同じWi-Fiで遊ぶ（LAN） Play on the same Wi-Fi (LAN)

Language

手順

  1. サーバーを起動します。
  2. 「ネットワーク」タブで LAN IP（例: 192.168.x.x）を確認。
  3. 友だちに「LAN IP:ポート」を共有。
  4. 友だちは Minecraft の「マルチプレイ」→「ダイレクト接続」で入力して接続。

うまくいかないとき

  • 接続できない — 全員が同じ Wi-Fi / ルーターに接続しているか確認。
  • IP が見つからない — ネットワークタブで「ローカル IP」を確認。192.168.x.x または 10.x.x.x 形式のもの。
  • Firewall ブロック — Windows Firewall が受信をブロックしている場合があります。MaiPilot の Firewall ルール取得機能で確認。
  • ポートが違う — server.properties のポート番号と接続先のポートが一致しているか確認。
  • Minecraft のバージョンが違う — サーバーとクライアントのバージョンを揃えてください。

外部からの接続（インターネット経由）

LAN 外の友だちと遊ぶにはポート開放が必要です。

Steps

  1. Start the server.
  2. Check the LAN IP (e.g. 192.168.x.x) in the Network tab.
  3. Share "LAN IP:Port" with friends.
  4. Friends enter it via Minecraft Multiplayer → Direct Connection.

Troubleshooting

  • Can't connect — Verify all players are on the same Wi-Fi / router.
  • Can't find IP — Check "Local IP" in the Network tab (192.168.x.x or 10.x.x.x).
  • Firewall block — Windows Firewall may block inbound connections. Use MaiPilot's firewall rule tool to check.
  • Wrong port — Make sure the server.properties port matches the connection port.
  • Version mismatch — Server and client Minecraft versions must match.

Playing over the internet

To play with friends outside your LAN, you need port forwarding.

よくあるポイント

  • 同じ Wi-Fi に接続している必要があります。
  • ポート番号はサーバー設定と一致させます（デフォルト: 25565）。
  • サーバー PC がスリープすると接続が切れます。電源設定を確認してください。

Common notes

  • All players must be on the same Wi-Fi.
  • Make sure the port matches the server settings (default: 25565).
  • If the server PC sleeps, the connection drops. Check power settings.
