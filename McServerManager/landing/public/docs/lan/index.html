同じWi-Fiで遊ぶ（LAN） Play on the same Wi-Fi (LAN)

Language

手順

  1. サーバーを起動します。
  2. 「ネットワーク」タブでLAN IPを確認。
  3. 友だちに「LAN IP:ポート」を共有。

Steps

  1. Start the server.
  2. Check the LAN IP in the Network tab.
  3. Share “LAN IP:Port” with friends.

よくあるポイント

  • 同じWi-Fiに接続している必要があります。
  • ポート番号はサーバー設定と一致させます。

Common notes

  • All players must be on the same Wi-Fi.
  • Make sure the port matches the server settings.
